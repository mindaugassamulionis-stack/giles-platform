# Storefront Design System (Neo-Scientific Premium)

> **Vision:** A high-end, trustworthy e-commerce experience for premium supplements.
> **Vibe:** Scientific, Clean, Natural, Energetic.
> **Tech:** Tailwind CSS v4, Framer Motion, Radix UI.

## 1. Color Palette

We move away from clinical white to a warmer, premium base with vibrant accents.

### Core Colors

## 2. Typography

### Headings: **Outfit** (Google Fonts)
Geometric, modern, approachable.
- `text-4xl font-bold tracking-tight`: Hero Headers
- `text-2xl font-semibold`: Section Titles

### Body: **Inter** or **Geist Sans**
Clean, highly legible for product descriptions.

### Technical / Data: **Geist Mono** or **JetBrains Mono**
*Crucial for the "Scientific" aesthetic.* Used for:
- Price (`€49.00`)
- Dosage (`500mg`)
- Ingredients list.
- Badges (`ORGANIC`)

## 3. Award-Winning Mechanics (The "Site of the Day" Factors)

To win design awards (Awwwards, FWA), we must transcend "usability" into "experience".

### A. The "Fluidity" Core (Lenis Scroll)
Native browser scrolling is too jagged for premium storytelling.
- **Tech**: React-Lenis (Smooth Scroll).
- **Effect**: The page glides with momentum/inertia.
- **Parallax**: Images move slower than text (`y: ["0%", "20%"]`).

### B. Editorial Typography (The "Vogue" Science)
Breaking the grid.
- **Gigantic Headers**: 120px+ (Desktop) headers that bleed off-screen.
- **Tiny Technical Details**: 10px Mono fonts scattered like lab notes.
- **Mix**: Serif (Editorial) + Mono (Science).
- **Reveal**: Text doesn't just appear; it unmasks line-by-line (`clip-path` reveals).

### C. Immersive Interaction
- **Magnetic Buttons**: Buttons shouldn't be static. They should magnetically stick to the cursor within a radius.
- **Custom Cursor**: A small dot that expands into a ring/lens when hovering products.
- **WebGL Hero**: The 3D bottle isn't a PNG. It's a `Three.js` / `Spline` scene that rotates as you scroll.

## 4. Component Library (Refined)

### Buttons (Magnetic)
- **Primary**:
    - **Shape**: Pill-shaped, but fluid.
    - **Behavior**: Magnetic (framer-motion).
    - **Hover**: Text scrambles (e.g., "BUY" cycles random chars -> "BUY").

### Cards (The "Lab Sample")
- **Concept**: A sterile, vacuum-sealed look.
- **Interaction**:
    - Default: Clean, minimal info.
    - Hover: The product image scales 1.1x, the background dims, and chemical structures (SVGs) fade in behind the bottle.
    - Cursor: Changes to "VIEW" text.

### The "Aura" Gradient
Instead of solid colors, we use "Orbs" of light that move behind the glassmorphism layers.
- `bg-gradient-radial from-emerald-500/30 to-transparent`
- Animated via CSS keyframes or R3F shader.

### Badges / Pills
- **"Organic"**: `bg-green-100 text-green-800`
- **"Best Seller"**: `bg-amber-100 text-amber-800`
- **"New"**: `bg-lime-100 text-lime-800`

## 5. Experience & Narrative (The 2026 Winner Factor)

To win in 2026, we don't just show products; we tell a **Scientific Story**.

### A. Narrative Scrollytelling
- **Deconstruction**: As the user scrolls down the PDP, the 3D bottle *explodes* (deconstructs) into its ingredients.
- **Scroll-Triggered Text**: Text doesn't just sit there. The "Benefits" section locks in place (sticky), and the benefits scroll *over* the 3D model.

### B. Contextual Theming (Adaptive Backgrounds)
We do not use a simple "Dark Mode toggle". We use **Sectional Theming**.
- **Hero Section**: `Light Mode` (Clean, Approachable).
- **Science/Ingredients Section**: Smooth transition to `Dark Mode` (Deep Emerald/Black) to signal "Deep Dive" / "Technical".
- **Reviews**: Back to `Light Mode`.
- **Effect**: The background color creates a wrapper that sets the mood for the content type.

### C. Performance (The Invisible Luxury)
- **Lighthouse 100**: An award-winning site cannot lag.
- **Technique**: Use GLSL Shaders for effects (GPU) instead of heavy videos (CPU/Network).
- **Core Web Vitals**: LCP < 0.8s.

## 7. The God-Tier Polish (The Invisible Art)

To be the "Best in the World", we must design what the user *feels* but doesn't *see*.

### A. Sonic Branding (UI Sound)
The web is silent. God-tier sites are not.
- **Hover**: High-frequency "Tick" (15kHz, -20dB) - subtle metallic click.
- **Success**: A low-end "Thrum" (80Hz) when adding to cart.
- **Tech**: `use-sound` with custom synth samples (not stock sounds).

### B. Optical Typography settings
True typography nerds know the difference.
- **Ligatures**: "fi", "fl" enabled.
- **Tabular Figures**: For prices (`font-variant-numeric: tabular-nums`).
- **Kerning**: `text-rendering: optimizeLegibility`.
- **CSS**: `font-feature-settings: "ss04" on, "cv01" on, "salt" on;` (Stylistic sets for 'a', 'g', 'y').

### C. The "Boot Sequence" (Pre-loader)
No spinning wheels.
- **Concept**: The "System Initialization".
- **Visual**: A code terminal flickers -> 3D Geometry assembles -> The UI "Injects" itself into the DOM.
- **Duration**: Exact 1.2s (Hidden loading).

### D. The 404 Experience
A broken link isn't an error; it's a "Void".
- **Visual**: Interactive WebGL black hole that sucks in the cursor.
- **Message**: "Reality Fragment Not Found."
